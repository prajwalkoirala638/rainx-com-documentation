# About

This repository is a centralized collection of publicly available **Safety Data Sheets (SDS)**, **Material Safety Data Sheets (MSDS)**, **Technical Data Sheets (TDS)**, product literature, and related documentation published by manufacturers.

The primary objective is to preserve, organize, and make these technical documents easier to locate for educational, engineering, scientific, and research purposes.

Safety Data Sheets are among the most valuable publicly available technical documents because they provide standardized information regarding chemical products, including hazards, handling procedures, physical characteristics, storage recommendations, emergency response procedures, environmental information, and regulatory classifications.

This repository acts as a searchable reference library for students, educators, researchers, engineers, industrial professionals, and anyone interested in understanding commercial chemical products.

# What is an SDS?

A Safety Data Sheet (SDS) is a standardized document designed to communicate information about hazardous and non-hazardous chemical products.

Modern SDS documents generally follow the Globally Harmonized System (GHS), which organizes information into 16 standardized sections.

Typical sections include:

1. Identification
2. Hazard Identification
3. Composition / Information on Ingredients
4. First Aid Measures
5. Fire Fighting Measures
6. Accidental Release Measures
7. Handling and Storage
8. Exposure Controls / Personal Protection
9. Physical and Chemical Properties
10. Stability and Reactivity
11. Toxicological Information
12. Ecological Information
13. Disposal Considerations
14. Transport Information
15. Regulatory Information
16. Other Information

Understanding these sections is an essential skill for engineers, laboratory workers, emergency responders, environmental professionals, and manufacturing personnel.
